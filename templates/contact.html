Privacy & feedback

Your media, handled briefly.

Authenfy processes files on the server running this app. It deletes the uploaded file after the request finishes. It stores analysis receipts containing the SHA-256, model identity, scores and timestamps, without the original filename or media. Crash interruption may leave a temporary file for the server operator to remove.

Receipt IDs act as unguessable access tokens. Anyone with an ID can retrieve that receipt. Keep the ID private. A browser refresh clears the preview; downloadable receipts remain wherever you save them.

The app uses no analytics, advertising cookies, cloud inference API or third-party browser scripts. The model download command contacts Hugging Face to install the pinned public model. The operator controls database retention and signing-key backups. The local deployment does not offer user accounts or a deletion portal.

Report an issue

Share reproducible steps, environment details and redacted error output. Avoid posting private media or receipt IDs publicly.
